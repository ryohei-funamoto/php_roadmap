# 理解度の振り返り：変数と型

- 日付：2026-11-03
- 根拠：練習問題 `exercise.php`（6問）の解答と、学習中の質問

## 総合評価

**基本は身についている。** 6問ともコードは正しく動き、実行前の予想は16個中13個が当たった。
外れた3個は、次の2点に関するもの。

- `echo` と `var_dump` の出力の違い
- 文字列からのキャスト（`(bool) "0"`、`(int) "3.9kg"`）

| 項目 | 理解度 | 根拠 |

## 良かった点

- **分からないときに「分からない」と書いた。** 推測で埋めないので、復習すべき箇所がはっきりする。
- **結果を見て終わりにせず、理由を確かめている。** `var_dump($undefined)` の `NULL` がどこから来るのか、`0 == ""` がなぜ `false` なのかを質問した。
- **資料の不自然な点に気づいている。** `README.md` の表で、`"0.0"` と `"false"` の並びの問題を指摘した。

## 補強するとよい点

1. **`echo` と `var_dump` は、同じ値でも表示が違う**
   - `echo null` は何も表示しない（`null` が空文字列に変換される）
   - `var_dump(null)` は `NULL` と表示する
2. **文字列からのキャストのルール**
   - `(bool)` で `false` になる文字列は `""` と `"0"` だけ
   - `(int) "3.9kg"` は、先頭の数値部分 `3.9` を読み取り、小数点以下を切り捨てて `3` になる
3. **float を int として返すときの端数**
   - `taxOf(1005)` は `100.5` を暗黙に `100` へ変換する。端数の処理は明示的に書く
   - 現在の設定では Deprecated が表示されないので、気づきにくい

## 次の分野へのつながり

- `(bool)` の変換ルールは、次の「制御構文」の `if` の条件でそのまま使う。
- 暗黙の型変換は、「オブジェクト指向」の Type Declarations で `declare(strict_types=1)` と一緒に学ぶ。
